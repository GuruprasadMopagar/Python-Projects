# Python-Projects
A collection of Python projects developed to practice programming fundamentals, problem-solving, user input handling, conditional statements, calculations, and real-world application development.

1. 🏧 ATM Project
A simple console-based ATM application developed using Python. It allows users to perform basic banking operations such as checking account balance, depositing money, withdrawing money, and exiting the application. The project demonstrates the use of conditional statements, loops, functions, and user input handling.

2. 💰 Expense Tracker
A Python-based expense tracking application that allows users to record and manage their daily expenses. It helps categorize expenses and calculate spending information, making it easier to understand personal spending habits. The project demonstrates input handling, calculations, conditional statements, and basic data management.
